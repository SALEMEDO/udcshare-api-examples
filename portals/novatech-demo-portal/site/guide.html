CENTRE D'AIDE · TUTORIEL OFFICIEL

Bienvenue dans le guide NOVATECH.

Retrouve ici les étapes pour créer ton compte, connecter ta propre API UDCShare et lancer tes premiers essais. Tu n'as pas besoin d'ouvrir Render pour consulter ce tutoriel.

Dans ce guide 1. Démarrer2. Connecter une API3. Lancer les tests4. Sécurité5. Stockage6. Informations techniques

1. Créer ton espace développeur

  1. Ouvre la plateforme NOVATECH.
  2. Choisis « Créer un compte » et renseigne ton nom, ton adresse e-mail et un mot de passe sécurisé.
  3. Confirme ton adresse e-mail si cette étape est demandée par le service de connexion.
  4. Connecte-toi. Ton espace et tes données sont personnels.

2. Connecter ta propre API

  1. Dans « Connecter une API », donne un nom à ta configuration.
  2. Saisis l'adresse HTTPS de ton API.
  3. Ajoute l'identifiant de ton projet et ta clé API personnelle.
  4. Clique sur « Enregistrer ma configuration ». La clé est effacée du formulaire après l'enregistrement.
Utilise uniquement une clé et un projet que tu es autorisé à utiliser. Pour apprendre, privilégie un projet Sandbox.

3. Lancer tes premiers tests

Sélectionne une connexion enregistrée, puis choisis l'une des démonstrations :

  • État du projet : vérifie la disponibilité de l'API et du projet.
  • Mes fichiers : affiche les fichiers accessibles dans ton projet.
  • Consommation API : consulte les informations de plan et d'utilisation disponibles.

Les résultats et l'historique des essais sont visibles dans ton espace personnel. Ils sont conservés pour ton compte afin que tu puisses les retrouver après une nouvelle connexion.

Attention : ces appels sont réels. Ils utilisent ton API, tes droits et les quotas de ton projet. Vérifie toujours le projet sélectionné avant de lancer un test.

4. Protection de tes identifiants

  • Ta clé API n'est pas ajoutée aux variables d'environnement Render.
  • Elle est transmise au backend par HTTPS, puis chiffrée avec AES-256-GCM.
  • La clé en clair n'est pas renvoyée au navigateur ni écrite dans les journaux.
  • Chaque compte ne peut accéder qu'à ses propres configurations et historiques grâce aux règles d'isolation de la base.
  • Ne partage jamais ta clé API, ton mot de passe ou tes identifiants.

5. Où sont conservées les données ?

NOVATECH conserve dans Supabase les informations du compte démo, les configurations API chiffrées et l'historique synthétique des tests.

Les fichiers binaires ne sont pas stockés dans Supabase Storage par NOVATECH. Ils restent dans le Google Drive relié au projet API que tu testes.

6. Informations techniques

Endpoints testés

GET /api/v1/apps/{projectId}/status GET /api/v1/apps/{projectId}/files?limit=10 GET /api/v1/usage

Conseils pratiques

  • Utilise des données fictives et évite les documents personnels.
  • Ne teste jamais avec la clé d'un autre client.
  • Vérifie l'adresse de l'API et l'identifiant du projet avant chaque essai.
  • Supprime les configurations que tu n'utilises plus depuis ton espace.
