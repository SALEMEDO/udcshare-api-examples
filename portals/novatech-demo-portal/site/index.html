OUTIL RÉSERVÉ AUX AGENTS

Gestion du stockage NOVATECH

Ouvrez le projet UDCShare pour administrer la connexion Drive. Connectez-vous avec le compte UDCShare qui possède le projet NOVATECH et ses dossiers. UDCShare vérifiera vos autorisations.

  • Depuis ce portail : voir si le Drive est connecté, son type (entreprise ou individuel), l’état de l’autorisation Google, le compte connecté, ouvrir le lien officiel de reconnexion, déconnecter le Drive (réversible) ou révoquer complètement l’autorisation Google.
  • Depuis le projet UDCShare (compte propriétaire) : changer de compte Google (nouveau consentement) ou retirer définitivement le Drive avec suppression des fichiers. L’API publique ne permet pas ces deux opérations avec une clé API seule.

Si la clé API a été révoquée, créez-en une nouvelle dans le projet UDCShare et remplacez le secret côté serveur Render.
