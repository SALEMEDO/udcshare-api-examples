# Démo 2 — Playground API NOVATECH

Dossier autonome de la démonstration développeur / Playground API.

## Structure
- `site/app.html` et `site/app.js` : Playground et parcours de connexion.
- `site/client-portal.html` et `site/client-portal.js` : portail de démonstration associé.
- `site/config.js` : adresse de l’API NOVATECH.
- `site/engagement.js` : vues et J’aime.
- `site/styles.css`, `site/uix-pro-max.css`, `site/home.css`, `site/novatech-logo.svg` : ressources.
- `site/index.html` et `site/guide.html` : accueil et guide associés.

## API commune
`https://api-novatech-test.udcshare.com`. Aucune clé secrète ne doit être exposée dans le navigateur.

## Lancement
Servir le dossier `site` avec un serveur HTTP statique ; ne pas ouvrir les pages en `file://`.
