Exemple : déposer un fichier avec cURL

Les appels projet utilisent une clé API et un identifiant utilisateur externe. Gardez toujours la clé privée côté serveur.

curl -X POST "https://udcshare.com/api/v1/apps/PROJECT_ID/files" \
  -H "X-API-Key: $UDCSHARE_API_KEY" \
  -H "X-External-User-ID: user-123" \
  -F "file=@document.pdf"
NOVATECH utilise les clés API personnelles des visiteurs, chiffrées dans leur espace. Ne soumettez aucun document personnel. Les tests peuvent consommer les quotas de votre propre projet UDCShare.
